Final Year BCA Capstone Project

MediConnect – Medical Platform

An end-to-end multi-module healthcare management system integrated with a GPS-enabled Flutter Android app for instant doctor discovery and appointment booking.

Flutter Dart Python HTML5/CSS3 JavaScript Bootstrap SQL Database

Project Overview

MediConnect is a comprehensive medical platform designed to bridge communication gaps between patients, healthcare institutions, physicians, and pharmacies. Developed as a final-year project for the Bachelor of Computer Applications (BCA) program, MediConnect incorporates multi-role authentication, real-time GPS hospital tracking, automated appointment scheduling, and digital prescription workflows.

Architecture & Module Specifications

1. Admin Module

Centralized portal for platform governance. Admins verify hospital registrations, manage system settings, inspect audit logs, and oversee overall data integrity.

2. Hospital Module

Allows hospital administrators to maintain institutional profiles, manage doctor rosters, configure consultation timings, set department fees, and publish operational details.

3. Doctor Module

Enables medical practitioners to manage daily schedules, view incoming patient appointments, communicate directly with patients, and generate digital prescriptions.

4. Pharmacy Module

Facilitates medicine inventory tracking, prescription verification, order fulfillment status, and pricing coordination with patients and doctors.

5. Flutter Mobile Application (Patient GPS Portal)

Android App built with Flutter & Dart

The mobile application leverages GPS location services allowing users to locate nearby hospitals based on current proximity, view available doctor profiles and specialties, check consultation timings/fees, book appointments, and securely view digital prescriptions.

Key Learnings & Engineering Skills

  • Mastered multi-role database architecture with relational SQL constraints, foreign keys, and transaction integrity.
  • Implemented Flutter state management and UI widgets for a smooth mobile experience across Android devices.
  • Integrated location-based GPS features to dynamically calculate distances and query nearby hospitals in real time.
  • Applied Python backend scripts, HTML5, CSS3, JavaScript, and Bootstrap to craft responsive web administration interfaces.
