# Sravan Shankar P - Futuristic Cyberpunk Portfolio

This is a futuristic, highly interactive cyberpunk-themed personal portfolio built with HTML, CSS, JavaScript, and Vite.

## Features
- **Mouse Glow Tracking**: Subtle background ambient light following user coordinates.
- **Dynamic Typing/De-typing Cursor**: Interactive roles display in the hero section.
- **Interactive Skill Meters**: Populates percentages smoothly as you scroll into view.
- **Console Terminal Simulator**: Simulates diagnostic boots and system status logs.
- **Glassmorphic Contact Buttons**: Responsive circular links that glow on hover.
